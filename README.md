# Word-Counter-Program-Python

Author: Babyface Mokoena
Language: Python

## Description

The Word Counter Program is a simple Python application that reads a text file and counts the total number of words in it. It demonstrates basic file handling, string manipulation, and exception handling in Python. The program prompts the user to enter a file name, reads the file content, splits the text into words, and displays the word count. It also handles errors such as missing files gracefully.

## Features

Reads content from a text file

Counts the total number of words

Handles file not found errors

Simple and beginner-friendly implementation

## How to Run

Make sure Python 3 is installed.

Navigate to the project directory.

Run the program using:

python word_counter.py
